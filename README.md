# Правила аудитов ADDU

Рабочие правила агентства ADDU для аудитов сайтов. Дополняют общие методики из
`addu-audit-skills` и **имеют приоритет** над ними.

## Что где лежит

| Файл | О чём |
|---|---|
| `audit-152fz.md` | Как делать аудит по 152-ФЗ: порядок работы, что открывать, правила достоверности, статусы |
| `rules-addu.md` | Скидка 30%, формат выдачи клиенту, публикация маркетинговых аудитов |
| `letters.md` | Письма клиенту: ответ на отклик и сопроводительное к аудиту |
| `CHANGELOG.md` | Что менялось и когда |

## Как подключить

Склонировать рядом с папкой скиллов:

```bash
git clone <адрес этого репозитория> addu-audit-rules
```

В начале работы сказать ассистенту:

> Читай папку addu-audit-rules и следуй ей. Эти правила главнее общих методик.

В Codex можно прописать то же самое в `AGENTS.md`, тогда правила подхватятся сами.

## Как обновляться

```bash
cd addu-audit-rules && git pull
```

Делать это перед началом рабочего дня. Все правки правил приходят отсюда, отдельно ничего
пересылать не нужно.

## Доступы

Пароли и доступы в репозитории не хранятся. FTP для публикации выдаётся лично и лежит только
на компьютере в файле `publish-credentials.local.md`.
