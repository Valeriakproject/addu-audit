# Библиотека конверсионных компонентов

Стандартизированные блоки для аудита и сборки страниц. При аудите — сверяй каждую страницу с этим набором.

## Компоненты

### HERO — Первый экран
Позиционирование + главный CTA. H1 повторяет поисковый интент. Подзаголовок: что получите. 2 CTA: главный + вторичный.

### PROOF — Полоса доверия
3-5 коротких фактов в строку. Без воды и абстракций. Ставить под Hero на каждой ключевой странице.

### PORTFOLIO — Портфолио + цены
Реальные работы с ценами. Фото в контексте (на фасаде, в интерьере), а не рендеры. CTA: «хочу так же — рассчитать для меня».

**ВАЖНО:** Идентифицируй по ФУНКЦИИ, а не по названию. «Наши цены» с фото работ = PORTFOLIO + PRICING.

### IDENTIFY — Идентификация
«Для кого»: помочь посетителю узнать себя. Плитки по типу бизнеса, задаче или сценарию. Клик → фильтр портфолио.

### PRICING — Ценообразование
«Что влияет на цену» или «от X₽». Прозрачность снимает страх неизвестности. НЕ «цена по запросу» (убивает конверсию из рекламы).

### TRUST — Снятие рисков
Гарантия, отзывы, документы, согласование. Ставить РЯДОМ с моментом принятия решения, а не внизу страницы.

### QUIZ — Подбор / квиз
3-5 вопросов максимум. Обязательно вариант «не знаю» (чтобы не терять лид). Выход: расчёт + рекомендация.

### PROCESS — Этапы работы
Что будет после заявки: 5 шагов. Снимает страх первого шага. Микротекст: «Ответим за 15 минут».

### FAQ — Частые вопросы
6-8 вопросов, которые «убивают» заявки если их нет. Размещать на категориях и карточках.

### NEXT_STEP — Следующий шаг
Форма с правильными полями + «что нужно указать» + «что будет дальше» (SLA). Микротекст под кнопкой.

### CROSS_SELL — Кросс-продажа
Мост в смежное направление. «Вместе с X часто заказывают Y». Мягкий, не навязчивый.

## Эталонные структуры по типам страниц

### Главная (B2B, multi-product)
HERO → PROOF → PRODUCTS (с ценами, иерархия) → PORTFOLIO → TRUST → QUIZ → Отзывы → FAQ → NEXT_STEP

### Продуктовая / Услуга (основная)
HERO → PROOF → PORTFOLIO → IDENTIFY → Типы/варианты → PRICING → PROCESS → TRUST → FAQ → NEXT_STEP → CROSS_SELL

### Категория / Каталог
HERO → PROOF → Фильтры + листинг → QUIZ → TRUST → FAQ → NEXT_STEP

### Карточка товара
HERO (с ценой/параметрами) → Характеристики → PORTFOLIO/Примеры → TRUST → PROCESS → NEXT_STEP (форма) → FAQ → CROSS_SELL

### Услуга-сервис (согласование, консалтинг)
HERO → Почему важно (триггер страха) → PROCESS → PORTFOLIO/Кейсы → TRUST → FAQ → NEXT_STEP → CROSS_SELL
