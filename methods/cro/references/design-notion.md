# Design System — тёплый светлый стиль addu (обновлено 2026-06-22)

Дизайн-спецификация для HTML-deliverable аудитов. База — спокойная «документная» типографика
Notion, но палитра и компоненты приведены к **тёплому светлому стилю addu** с янтарным акцентом
(эталон — пакет аудитов 152-ФЗ). Цель — спокойный, «дорогой», «документный» вид без признаков
ИИ-генерации.

## Принципы
- Много воздуха, крупная типографика, спокойствие. Не «дашборд».
- Разделять контент **тонкими линиями (hairline)**, а не обводить каждый элемент в карточку.
- Цвет — точечно и приглушённо. Янтарный акцент addu + пастельные плашки, не неон.
- Мягкие скругления (карточки 12px, находки/панели 14px, hero 18px). Допустим один тонкий
  тёплый градиент в hero. Без теней-свечений, без фейковых браузерных рамок, без эмодзи в заголовках.

## Типографика
- Семейство: `Inter, -apple-system, BlinkMacSystemFont, 'Segoe UI', sans-serif`
- Body: 14–16px / line-height 1.6–1.7, цвет `#202124`
- H1 (hero): Inter **700**, крупный (30–36px), **letter-spacing −0.02em**
- H2/подписи: 12px, weight 600, uppercase, цвет `#68707A`, letter-spacing +0.04em
- Eyebrow (тип аудита над H1): 11px, weight 700, uppercase, цвет `#9A6713`, letter-spacing +0.08em
- Моноширинный (только для URL/кода): системный `ui-monospace, 'SF Mono', Menlo, monospace`

## Компоненты
- **Hero:** eyebrow + H1 (домен) + описание на тёплом градиенте, скругление 18px; справа счётчики.
- **Сводка-карточки:** статус / что значит / объём — белые карточки 12px под hero.
- **Карточка-находка `.issue`:** белая карточка 14px, заголовок слева + пилюля-бейдж справа,
  внутри абзацы «Что увидели / Почему важно / Что поправить».
- **Вкладки (tabs):** серый текст неактивных, активная — тёмный текст + **янтарная** нижняя граница.
- **Строки списков (проблемы, задачи):** без рамок, разделены hairline снизу, padding ~12px.
- **Callout / «главная находка»:** тёплый фон `#FAF7F2` + левая **янтарная** полоса 3px.
- **Итог стоимости `.total`:** тёплая плашка `#FFF8EC`, крупная сумма справа.
- **Severity-бейджи:** Критично = красный, Важно = оранжевый, Рекомендуется = синий,
  Требует проверки = серый (пары текст/фон из таблицы выше).

## Применение к аудиту
См. [[feedback-audit-design]] и [[project-cro-audit-skill]]. Стартовать с болванки
`../../assets/base-template.html` (палитра, hero, бейджи, контакт уже встроены). При переносе
старых аудитов — поменять значения CSS-переменных в `:root` под существующими именами и таблицу
`COMP_COLORS` в JS на тёплые цвета (акцент `#F6A21A`). Эталон вида: пакет аудитов
`addu-152fz-toolkit` (напр. `documents/a-center-ru-152fz/audit-a-center-ru.html`).
