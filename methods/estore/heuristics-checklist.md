# Heuristics Checklist: детальная оценка e-com по разделам воронки

Этот чеклист — основной инструмент эвристического аудита. Пройди по всем блокам, но **фокус — на 5-10 крупных проблемах**, а не формальной галочке по каждому пункту.

Принцип: для каждого пункта задавай себе вопрос "что бы сейчас остановило/смутило среднестатистического пользователя с мобильного?"

---

## 1. Homepage (главная страница)

Главная — это не "витрина для Google", а "первая проверка на доверие". 70% посетителей решают "оставаться или уходить" за первые 5-10 секунд.

### 1.1 Выше сгиба (above the fold)
- [ ] **Value proposition** понятен за 3 секунды? (что за магазин, что продают, почему сюда)
- [ ] Есть явный CTA (каталог, конкретный товар, акция)?
- [ ] Логотип кликабелен и ведёт на главную?
- [ ] Телефон и/или онлайн-чат видны сразу (для премиум-сегмента особенно)?
- [ ] Мобильный хедер: компактный, без ненужных элементов?

### 1.2 USP / Преимущества
- [ ] Чётко сформулированы 3-5 ключевых преимуществ?
- [ ] Они **конкретные** ("доставка за 2 часа"), а не абстрактные ("качественный сервис")?
- [ ] Иконки и тексты согласованы? (частая ошибка — красивые иконки + пустые слова)

### 1.3 Навигация
- [ ] Категорий в главном меню не слишком много (идеально 5-9)?
- [ ] Структура меню очевидна (смешение брендов и категорий — плохой знак)?
- [ ] Выпадающие меню не обрывают опыт (не закрываются случайно)?
- [ ] На мобильной версии гамбургер-меню удобно открывается и закрывается?

### 1.4 Товарные блоки
- [ ] Есть блоки "Хиты продаж", "Новинки", "Акции"? (Помогают пользователю, который не знает, что именно хочет)
- [ ] Акции и скидки выделены визуально (но не кричаще)?

### 1.5 Trust signals
- [ ] Реальный адрес, телефон, email (не только форма обратной связи)?
- [ ] Реквизиты юрлица внизу?
- [ ] Сертификаты, награды, упоминания в СМИ (если есть)?
- [ ] Отзывы (свои блоки или интеграция с Яндекс.Маркетом, Google)?
- [ ] Годы работы на рынке, количество клиентов/заказов (социальное доказательство)?

## 2. Каталог и страница категории (PLP)

Страницы листинга — вторые по посещаемости после главной. Это место, где пользователь выбирает, что смотреть дальше.

### 2.1 Структура и навигация
- [ ] Хлебные крошки видны и корректно отображают путь?
- [ ] Понятно, сколько всего товаров в категории (счётчик)?
- [ ] Подкатегории показаны наглядно (плитки с картинками, а не только текст)?

### 2.2 Фильтры
- [ ] Фильтры **релевантны** категории (для iPhone — объём памяти, цвет, год; для одежды — размер, цвет, бренд)?
- [ ] Применённые фильтры видны и легко сбросить?
- [ ] AJAX-обновление списка без перезагрузки?
- [ ] **Пустое состояние** (когда фильтры не дали результатов) — адекватно обработано?
- [ ] На мобильной — фильтры в удобном формате (например, bottom sheet)?

### 2.3 Сортировка
- [ ] Сортировка по: цена, новинки, популярность, рейтинг?
- [ ] Дефолтная сортировка логична для ниши?

### 2.4 Карточки товаров в листинге
- [ ] Качественное изображение (фон одинаковый, товар в фокусе)?
- [ ] При наведении — альтернативные ракурсы или hover-эффект?
- [ ] Цена чёткая, со скидкой (если есть) — перечёркнутая старая + новая?
- [ ] Быстрые действия: в корзину / в избранное / в сравнение — доступны прямо с карточки?
- [ ] Рейтинг и количество отзывов видны?
- [ ] Бейджи ("Хит", "Новинка", "-20%") используются умеренно?
- [ ] Если товара нет в наличии — чётко помечено + альтернатива?

### 2.5 Пагинация и загрузка
- [ ] Пагинация или бесконечная прокрутка (в идеале — "показать ещё" + пагинация)?
- [ ] При скролле сохраняется позиция (если вернулся с PDP обратно на категорию)?

## 3. Карточка товара (PDP) — критически важно

Это место, где принимается решение о покупке. PDP — часто слабейшее звено в рунете.

### 3.1 Визуальный блок
- [ ] Минимум 5-7 качественных фото с разных ракурсов?
- [ ] Возможность зума (без открытия новой вкладки)?
- [ ] Видео-обзор (для техники — почти обязателен)?
- [ ] 360°-обзор для сложных товаров?
- [ ] На мобильной — свайп между фото работает плавно?

### 3.2 Описание и характеристики
- [ ] **Конкретные, сканируемые характеристики** — таблица, а не портянка текста?
- [ ] Описание отвечает на вопросы "зачем мне это?" а не только "что это"?
- [ ] Для техники: совместимость, комплектация, гарантия — отдельными блоками?
- [ ] Размерные сетки (для одежды/обуви) — с подсказками "как измерить"?
- [ ] Вкладки/аккордеоны для длинных описаний?

### 3.3 Цена и покупка
- [ ] Цена **крупно и чётко** видна?
- [ ] Если есть скидка — виден размер экономии?
- [ ] **Рассрочка**: сразу указана сумма в месяц ("от X руб/мес")? (в РФ это сильнейший фактор)
- [ ] Кнопка "Купить" / "В корзину" — яркая, контрастная, не прячется при скролле?
- [ ] На мобильной — sticky CTA внизу экрана при прокрутке?

### 3.4 Trust-элементы на PDP
- [ ] Гарантия (срок, условия) — прямо на карточке, не "в футере"?
- [ ] Доставка: когда, сколько стоит — с калькулятором или явно?
- [ ] Возврат: можно ли, на каких условиях?
- [ ] Оплата: картой, наличными, рассрочка — иконки платёжек?
- [ ] Отзывы о конкретном товаре (не только о магазине в целом)?

### 3.5 Кросс-продажи и сопутствующие товары
- [ ] Блок "С этим товаром покупают" (аксессуары, расходники)?
- [ ] Блок "Похожие товары" (если этот не подойдёт)?
- [ ] Блок "Недавно просмотренные"?

### 3.6 Social proof
- [ ] Количество просмотревших товар / купивших / в корзинах ("Сегодня купили 12 раз")?
- [ ] Цитаты из отзывов видны сразу?
- [ ] Средняя оценка (звёзды) рядом с названием?
- [ ] Фото от покупателей (UGC) — сильный фактор доверия?

### 3.7 Наличие и сроки
- [ ] Чётко: "В наличии", "Под заказ", "Нет в наличии — сообщить о появлении"?
- [ ] Если под заказ — срок приезда указан?
- [ ] Если в наличии — сколько остатков (создаёт срочность, но не обманывать!)?

## 4. Поиск по сайту

Пользователи, которые используют поиск, конвертируются в 2-3 раза лучше. Но плохой поиск — убийца конверсии.

- [ ] Поисковая строка **заметна** на каждой странице?
- [ ] Автодополнение (suggestions) при вводе?
- [ ] Толерантность к опечаткам ("iPhpne" → "iPhone")?
- [ ] Поиск по артикулу работает?
- [ ] **Пустой результат** — внятно обработан (предложения, популярные товары)?
- [ ] Поиск понимает синонимы ("телефон" = "смартфон")?

---

## 5. Корзина

Корзина — точка, где пользователь становится "почти покупателем". Но 70% бросают корзины.

- [ ] **Стоимость доставки** видна в корзине (главная причина брошенных корзин в мире — 48% по Baymard)?
- [ ] Можно изменить количество прямо в корзине?
- [ ] Можно удалить товар (и отменить удаление)?
- [ ] Промокод — поле для ввода удобное?
- [ ] "Сумма к оплате" — чёткая, без сюрпризов?
- [ ] Кнопка "Оформить заказ" — доминирующий элемент?
- [ ] Блок "Возможно, вам понравится" (допродажа прямо в корзине)?
- [ ] Корзина **сохраняется** для возврата пользователя (cookie/локальное хранилище)?

---

## 6. Чекаут (оформление заказа) — самое больное место

Согласно Baymard, средний сайт теряет до 35% конверсии из-за плохого чекаута. Это самый прибыльный участок для оптимизации.

### 6.1 Общие принципы
- [ ] **Гостевой чекаут** доступен? (принудительная регистрация — худшая практика)
- [ ] Чекаут однопроцессный (или ступенчатый с явным прогресс-баром)?
- [ ] Минимум полей (только необходимое для доставки и связи)?
- [ ] Валидация полей в реальном времени (красное = ошибка сразу)?
- [ ] Автозаполнение работает (не ломается, например, на поле телефона)?
- [ ] Индекс подтягивается автоматически по адресу?

### 6.2 Доставка
- [ ] Варианты доставки **все** видны с ценами и сроками?
- [ ] Карта самовывоза с пунктами (для СДЭК, Boxberry)?
- [ ] Можно выбрать дату и время доставки?

### 6.3 Оплата
- [ ] Минимум 3 способа (карта, СБП, наличные при получении)?
- [ ] **Рассрочка** как способ оплаты — отдельно и заметно?
- [ ] Логотипы платёжных систем для доверия (Мир, Visa, Mastercard, СБП)?
- [ ] Если оплата картой — сохранение карты для повторных покупок?

### 6.4 Trust в момент оплаты
- [ ] HTTPS и зелёный замочек хорошо видны?
- [ ] Упоминание о безопасности передачи данных (PCI DSS, 3D-Secure)?
- [ ] Гарантия возврата, реквизиты — на финальной странице?
- [ ] Правила (оферта, обработка ПД) — прозрачно, чекбокс не скрыт?

### 6.5 Финальное действие
- [ ] Страница успеха: что дальше? (ждать звонка, email придёт, номер заказа)?
- [ ] Номер заказа крупно — можно запомнить/сохранить?
- [ ] Возможность отслеживания заказа (ссылка, email)?

---

## 7. Post-purchase

После покупки начинается настоящий маркетинг: повторные продажи в разы дешевле первой.

- [ ] Email-подтверждение заказа — красивое, с реквизитами, номером, инструкциями?
- [ ] SMS-уведомления на этапах (принят, отправлен, в пути, доставлен)?
- [ ] Трекинг заказа (страница со статусом или интеграция с курьерской службой)?
- [ ] Запрос отзыва после получения (через 5-10 дней)?
- [ ] Welcome-серия для новых покупателей?

---

## 8. Сквозные аспекты

### 8.1 Мобильная версия
- [ ] Нет горизонтального скролла?
- [ ] Кнопки крупные, попадаемые пальцем (минимум 44×44 px)?
- [ ] Шрифт читабелен без зума (минимум 14-16px)?
- [ ] Формы удобны (правильные типы клавиатур: tel, email, number)?
- [ ] Нет всплывающих баннеров, закрывающих контент на старте?

### 8.2 Скорость
- [ ] LCP (Largest Contentful Paint) < 2.5 сек?
- [ ] Картинки оптимизированы (WebP, lazy load)?
- [ ] CSS/JS минифицированы?
- [ ] CDN используется для статики?
- [ ] Нет блокирующих скриптов сторонних сервисов?

Инструменты для проверки: Google PageSpeed Insights, WebPageTest, GTmetrix.

### 8.3 Trust (общее)
- [ ] Политика конфиденциальности легко находится?
- [ ] Пользовательское соглашение на месте?
- [ ] Cookie-баннер соответствует 152-ФЗ (подтверждение согласия, а не принудительное)?
- [ ] Реквизиты юрлица, ОГРН/ИНН — в футере?
- [ ] Раздел "О компании" — с реальными людьми, офисом, фото?

### 8.4 Accessibility (A11y)
- [ ] Контрастность текста соответствует WCAG AA (минимум 4.5:1)?
- [ ] Клавиатурная навигация работает?
- [ ] Alt-тексты у изображений?
- [ ] Форма доступна для screen readers (правильные label)?

### 8.5 SEO-гигиена (влияет на трафик, трафик влияет на конверсию)
- [ ] Уникальные title/description на каждой странице?
- [ ] H1 единственный и релевантный?
- [ ] Микроразметка Schema.org (Product, Offer, AggregateRating)?
- [ ] Хлебные крошки размечены?

---

## Как использовать этот чеклист

1. **Не пробегай формально** — каждый раздел не обязан дать пункт в отчёт.
2. **Ищи "горячие точки"** — места, где сразу видно, что пользователь потеряется.
3. **Смотри в контексте ниши** — для магазина подарков trade-in не нужен, а для техники — критичен.
4. **Проверяй мобильную версию отдельно** — часто там в разы хуже, чем в десктопе.
5. **Записывай скриншоты** — они усилят отчёт.

Из сотен потенциальных пунктов отбирай **5-10 самых больных** и раскрывай их глубоко в отчёте.
