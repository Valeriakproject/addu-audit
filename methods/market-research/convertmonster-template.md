# Универсальный шаблон: Исследование рынка + Анализ компании + Сегменты роста + План действий

> **Как использовать:**
> Каждый раздел — отдельный промпт в Claude. Выполняйте последовательно.
> После каждого шага проверяйте результат на галлюцинации — особенно цифры.
> Итоговый документ собирается из всех разделов автоматически.

---

## БЛОК 0 — Подготовка перед началом

**Что загрузить в проект перед стартом:**
- [ ] Скил рыночного исследования (из базы знаний ConvertMonster)
- [ ] Данные компании (заполненный шаблон — см. Блок А ниже)
- [ ] Исследование рынка по нише (если есть в библиотеке CM)
- [ ] Сайт компании (URL для анализа)
- [ ] Данные по конкурентам (URL сайтов, скрины, если есть)

## ШАГ 1 — Исследование рынка

### Промпт 1.1 — Обзор рынка и ёмкость

```
Роль: Ты аналитик рынка с опытом в нише [НИША]. Используй данные из базы знаний проекта.

Контекст: Компания [НАЗВАНИЕ] работает в нише [НИША], регион [ГЕО].
Нужно понять рынок в котором работает компания.

Задача: Дай обзор рынка по структуре:
1. Ёмкость рынка (объём в ₽ или количество потенциальных клиентов в ГЕО)
2. Динамика за 2023–2025 — рост, стагнация, падение
3. Ключевые тренды 2025–2026 которые влияют на нишу
4. Доля онлайн vs офлайн (если применимо)
5. Сезонность — есть ли пики и провалы

Формат: Структурированный отчёт с заголовками. Цифры — с источником.
Ограничения: Если данных нет — пиши "данных нет, рекомендую уточнить в [источник]".
Не выдумывай цифры. Только факты или честные оценки с пометкой "оценочно".
```

### Промпт 1.2 — Конкурентный анализ

```
Роль: Ты маркетолог-аналитик. Используй данные из базы знаний проекта.

Контекст: Анализируем конкурентов компании [НАЗВАНИЕ] в нише [НИША], регион [ГЕО].
Конкуренты: [КОНКУРЕНТ 1 + URL], [КОНКУРЕНТ 2 + URL], [КОНКУРЕНТ 3 + URL].

Задача: По каждому конкуренту дай анализ:
1. Позиционирование — как себя продают, что обещают
2. Ценовой сегмент — дешевле / дороже / наравне
3. Сильные стороны — что делают хорошо
4. Слабые стороны — где явные пробелы
5. Что можно взять на вооружение

Итог: Таблица сравнения + 3 незакрытые ниши которые конкуренты упускают.

Формат: Сначала таблица (конкурент / сила / слабость / что взять),
затем список "3 пробела в рынке которые никто не закрывает".
Ограничения: Анализируй только то что видишь на сайтах. Не додумывай.
```

## ШАГ 2 — Анализ компании

### Промпт 2.1 — Аватары клиентов

```
Роль: Ты CustDev-аналитик с опытом в нише [НИША].

Контекст: Компания [НАЗВАНИЕ], ниша [НИША], регион [ГЕО], средний чек [ЧЕК].
Текущая аудитория по мнению клиента: [ЦА ИЗ БЛОКА А].

Задача: Опиши 2–3 аватара клиента по структуре:
— Имя, возраст, должность / роль
— Ситуация в которой находится
— Главная боль (что не даёт спать ночью)
— Что ищет / критерии выбора
— Главный страх и возражение
— Как принимает решение о покупке
— Где его найти (каналы, площадки)
— Какая фраза / сообщение зацепит

Формат: Отдельная карточка на каждого аватара.
Ограничения: Используй данные из базы знаний проекта. Аватары должны быть
реалистичными для ниши и ГЕО — не абстрактными персонажами.
```

### Промпт 2.2 — Анализ текущего маркетинга компании

```
Роль: Ты маркетолог-аудитор. Используй данные из базы знаний проекта.

Контекст: Компания [НАЗВАНИЕ], ниша [НИША].
Текущие каналы: [КАНАЛЫ ИЗ БЛОКА А].
Что пробовали: [ЧТО ПРОБОВАЛИ ИЗ БЛОКА А].
Сайт: [URL].

Задача: Дай честный аудит текущего маркетинга:
1. Что работает — сохранить и усилить
2. Что не работает — причина и что делать
3. Что не пробовали — и стоит ли
4. Главная точка потери лидов прямо сейчас
5. Быстрые wins — что даст результат за 30 дней без больших вложений

Формат: Пронумерованный список по каждому пункту.
Конкретные рекомендации, не общие слова.
Ограничения: Не хвали то что не заслуживает похвалы.
Если канал явно неэффективен — говори прямо с аргументом.
```

## ШАГ 3 — Топ-3 сегмента роста

### Промпт 3.1 — Анализ по 4 осям

```
Роль: Ты стратег-маркетолог. Используй все загруженные данные проекта.

Контекст: Компания [НАЗВАНИЕ], ниша [НИША], регион [ГЕО], чек [ЧЕК].
Результаты предыдущих шагов — в этом диалоге выше.

Задача: Найди сегменты роста по 4 осям:

1. АУДИТОРИИ — кто из потенциальных клиентов нас не замечает?
   Какие группы покупателей существуют на рынке, но мы к ним не обращаемся?

2. КОНКУРЕНТЫ — чьих клиентов мы можем забрать?
   Где конкуренты явно слабы, недовольны клиенты, есть пробел в предложении?

3. БОЛИ — какие смежные боли текущих клиентов мы не закрываем?
   Что они покупают у других после нас или вместо нас?

4. КАНАЛЫ И ГЕО — где нас нет, но должны быть?
   Каналы, площадки, районы, города где есть спрос но нет нашего присутствия?

Формат: По каждой оси — список гипотез сегментов (3–5 штук).
Затем итоговый топ-3 сегмента с обоснованием почему именно они.
Ограничения: Опирайся на реальные данные рынка и конкурентов из предыдущих шагов.
Не придумывай сегменты — обоснуй каждый.
```

### Промпт 3.2 — Оценка и приоритизация сегментов

```
Роль: Ты маркетолог-стратег.

Контекст: Сегменты роста из предыдущего шага.
Компания [НАЗВАНИЕ], ниша [НИША], доступный бюджет на тест: [БЮДЖЕТ если знаем].

Задача: Оцени каждый из топ-3 сегментов по матрице:
— Размер (сколько потенциальных клиентов)
— Достижимость (насколько легко до них дотянуться)
— Конкуренция (насколько плотно занят сегмент)
— Скорость результата (когда увидим первые лиды — 1 мес / 3 мес / 6 мес)
— Ресурс (сколько денег и времени нужно на вход)

Итог: Матрица приоритетов + рекомендация с каким сегментом начинать.

Формат: Таблица оценок + 1 абзац вывода по каждому сегменту.
```

## ШАГ 4 — План действий

### Промпт 4.1 — Пошаговый план

```
Роль: Ты маркетинговый директор. Используй все данные из проекта.

Контекст: Компания [НАЗВАНИЕ], ниша [НИША], регион [ГЕО].
Приоритетный сегмент роста: [СЕГМЕНТ ИЗ ШАГА 3].
Текущая ситуация: [КЛЮЧЕВЫЕ ВЫВОДЫ ИЗ ШАГОВ 1–3].

Задача: Составь пошаговый план действий на 3 месяца:

Месяц 1 — Быстрые wins (что даст результат за 30 дней):
— Конкретные действия, не общие слова
— Кто делает, сколько стоит, какой KPI

Месяц 2 — Системные изменения:
— Что внедряем надолго
— Тесты гипотез по новому сегменту

Месяц 3 — Масштабирование:
— Что масштабируем по результатам тестов
— Что останавливаем

Формат: Таблица по месяцам: действие / кто / ресурс / KPI / срок.
Ограничения: Только конкретные действия. Без «улучшить маркетинг» и «оптимизировать воронку».
Каждое действие — глагол + объект + измеримый результат.
```

### Промпт 4.2 — Проверка плана на реалистичность

```
Роль: Ты скептик-аналитик. Сыграй роль критика.

Контекст: Готовый план действий из предыдущего шага.

Задача: Найди слабые места плана:
1. Что мы переоцениваем — где ожидания завышены?
2. Какие риски не учли?
3. Где план зависит от факторов которые мы не контролируем?
4. Что первым сломается при нехватке бюджета или команды?
5. Что добавить чтобы план стал реалистичнее?

Формат: Нумерованный список замечаний + финальная скорректированная версия топ-5 действий.
```

## ШАГ 5 — Валидация результата

### Промпт 5.1 — Проверка на галлюцинации и сверка с реальностью

```
Роль: Ты редактор-аналитик. Твоя задача — найти ошибки, а не похвалить результат.

Контекст: Готовый исследовательский документ из предыдущих шагов этого диалога.
Ниша: [НИША], регион: [ГЕО].

Задача: Проверь документ по четырём критериям:

1. ГАЛЛЮЦИНАЦИИ С ЦИФРАМИ
   — Найди все цифры в документе
   — Есть ли у каждой источник или пометка "(оценочно)"?
   — Какие цифры вызывают сомнение и требуют проверки?
   Список подозрительных данных с рекомендацией где проверить.

2. ВЫДУМАННЫЕ СУЩНОСТИ
   — Названия конкурентов — проверь что они реально существуют
   — Названия источников — реальные ли исследования и организации?
   — Имена аватаров — не важно, но характеристики должны быть реалистичны для ниши и ГЕО

3. КОНКУРЕНТНЫЙ АНАЛИЗ
   — Данные о конкурентах получены с реальных сайтов или придуманы?
   — Если сайты не были прочитаны — отметь какие данные требуют ручной проверки

4. СПЕЦИФИЧНОСТЬ
   — Применим ли документ только к этой компании или подойдёт любому конкуренту?
   — Назови 3 места где текст слишком общий и нужна конкретика

Формат: Пронумерованный список проблем → по каждой: что не так + как исправить.
Если проблем нет — подтверди это явно с аргументом.
```

### Промпт 5.2 — Обогащение конкурентным анализом (если не хватает данных)

```
Роль: Ты конкурентный аналитик. Используй web search.

Контекст: Компания [НАЗВАНИЕ], ниша [НИША], регион [ГЕО].
Конкуренты из документа: [СПИСОК].

Задача: По каждому конкуренту найди в реальном времени:
1. Их текущий оффер на главной странице сайта
2. Цены (если открыты)
3. Как продвигаются — Директ, SEO, соцсети (по видимым признакам)
4. Отзывы клиентов — что хвалят, на что жалуются (2ГИС, Яндекс.Карты, отзовики)

Обнови раздел "Конкуренты" в документе реальными данными.
Отметь дату сбора данных.

Формат: Таблица конкурент / оффер / цена / продвижение / слабость по отзывам.
Ограничения: Только то что реально нашёл. Не додумывай.
```

После выполнения всех шагов — собери итоговый документ:

```
# Исследование рынка и план роста
[НАЗВАНИЕ КОМПАНИИ] · [НИША] · [ГЕО] · [ДАТА]

## 0. Резюме (5 ключевых выводов)
## 1. Рынок (объём, тренды, динамика)

## 3. Аватары клиентов (2–3 карточки)

## 5. Топ-3 сегмента роста (с матрицей оценки)
## 6. Пошаговый план на 3 месяца
## 7. Риски и оговорки
```

### Промпт для сборки итогового документа

```
Роль: Ты бизнес-аналитик. Используй все данные из базы знаний проекта.

Задача: Собери итоговый документ для компании [НАЗВАНИЕ] по структуре выше.
Используй результаты всех предыдущих шагов которые сохранены в проекте.

Раздел 0 — Резюме: 5 ключевых выводов которые собственник должен запомнить.
Каждый вывод — одно конкретное утверждение с цифрой или фактом.

Раздел 5 — Топ-3 сегмента роста: оформить как карточки с названием сегмента,
размером, почему сейчас, как войти, первый шаг.

Раздел 6 — План: таблица по месяцам, только конкретные действия.

Формат: Markdown. Заголовки H2/H3. Таблицы где нужна структура.
Объём: достаточный для работы, без воды.
Ограничения: Каждый факт — с источником или пометкой "оценочно".
Не включай рекомендации которые не подкреплены данными.
```

## Чеклист проверки готового документа

После получения итогового документа проверьте:

**Галлюцинации:**
- [ ] Все цифры рынка имеют источник или помечены «оценочно»
- [ ] Названия конкурентов — реальные компании (проверьте в поиске)
- [ ] CPL, конверсии, бюджеты — взяты из реальных данных или бенчмарков

**Качество:**
- [ ] Каждый аватар — узнаваемый реальный человек, не абстракция
- [ ] Каждое действие в плане — конкретное (глагол + объект + результат)
- [ ] Сегменты роста обоснованы данными, а не «кажется что»

**Применимость:**
- [ ] Документ специфичен для этой компании и ГЕО
- [ ] Убрать название компании — документ не должен подходить конкурентам
- [ ] Собственник может взять план и передать команде без дополнительных объяснений
