# Чекбоксы согласия для форм {{SITE_DOMAIN}} ({{CMS_NAME}})

- Согласие на обработку персональных данных: {{SITE_URL}}personal-data-consent/

## Унифицированный текст чекбокса (для всех форм, кроме подписки)

```text
Я даю согласие на обработку персональных данных на условиях Согласия на обработку персональных данных и подтверждаю, что ознакомлен(а) с Политикой обработки персональных данных.
```

Ссылки в тексте:
- «Согласия на обработку персональных данных» → /personal-data-consent/
- «Политикой обработки персональных данных» → /policy/

HTML-разметка (платформо-нейтральный пример):

```html
<label>
  <input type="checkbox" name="personalInfo" value="Y" required>
  Я даю согласие на обработку персональных данных на условиях
  <a href="/personal-data-consent/" target="_blank" rel="noopener">Согласия на обработку персональных данных</a>
  и подтверждаю, что ознакомлен(а) с
  <a href="/policy/" target="_blank" rel="noopener">Политикой обработки персональных данных</a>.<span class="required">*</span>
</label>
```

Требования к каждому чекбоксу:
- обязателен на клиенте (`required`);
- обязателен на сервере;
- не отмечен по умолчанию;
- ссылки открываются в новой вкладке.

## Форма подписки на рассылку — отдельная разметка

{{#if has_marketing_rasslyka}}
Подписка собирает email (ПДн) и одновременно активирует рассылку. По ст. 18 ФЗ «О рекламе» нужен отдельный чекбокс на согласие на рекламную рассылку.

```html
<form ...>
  <input type="email" name="email" placeholder="Email" required>

  <label>
    <input type="checkbox" name="personalInfo" value="Y" required>
    Я даю согласие на обработку персональных данных...
  </label>

  <label>
    <input type="checkbox" name="marketing" value="Y" required>
    Я даю согласие на получение информационных и рекламных сообщений по каналам: {{MARKETING_CHANNELS}}. Я понимаю, что могу отписаться в любой момент.
  </label>

  <button type="submit">Подписаться</button>
</form>
```
{{else}}
Клиент подтвердил, что рекламных рассылок нет. В форме подписки нужен только чекбокс согласия на обработку ПДн (email — это ПДн). Отдельный чекбокс на рекламу не добавляем.

```html
<form ...>
  <input type="email" name="email" placeholder="Email" required>

  <label>
    <input type="checkbox" name="personalInfo" value="Y" required>
    Я даю согласие на обработку персональных данных...
  </label>

  <button type="submit">Подписаться</button>
</form>
```

Если в будущем появятся рекламные рассылки — добавить отдельный чекбокс.
{{/if}}

- [ ] во всех формах сервер не принимает заявку без отметки чекбокса;

## Замечания по тексту

- везде использовать «персональных данных» (родительный падеж);
- избегать формулировок «принимаю условия передачи информации» — это не согласие на обработку ПДн.
