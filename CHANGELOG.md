# Изменения

## 09.09.2026 — версия 5

- Добавлен `market-express.md` — экспресс-разбор маркетинга для холодного контакта. Работает только
  по открытым источникам: сайт и путь покупателя, цены, конкуренты из выдачи, отзывы, видимые каналы,
  рыночные данные веб-поиском. Ничего у клиента не спрашивает.
- Причина: скилл полного маркетингового исследования требует бриф из 11 полей и на холодном лиде
  вставал, потому что спросить выручку и средний чек не у кого.
- В `AGENTS.md` добавлена таблица выбора методики под запрос.

## 09.09.2026 — версия 4

- Правило про запрет вопросов сужено до пресейла. Раньше оно распространялось на весь репозиторий
  и сломало бы полное маркетинговое исследование по ConvertMonster, где вводные у клиента собирать
  нужно. Теперь явно описаны два режима: пресейл по холодному контакту и работа с оплатившим клиентом.

## 09.09.2026 — версия 3

- Добавлено главное правило: аудиты пресейловые, делаются без контакта с клиентом. Ассистенту
  запрещено спрашивать выручку, средний чек, аудиторию, конкурентов и приоритетные запросы.
  Недостающее помечается как «требует уточнения у клиента», работа не отменяется.
  Причина: на маркетинговом и ИИ-аудите ассистент вставал и требовал вводные, которых взять негде.

## 07.09.2026 — версия 2

Репозиторий стал самодостаточным скиллом по 152-ФЗ, а не только набором правил.

- Добавлен шаблон отчёта `assets/report-template.html` со встроенным стилем блока скидки. Раньше
  вёрстку приходилось придумывать каждый раз, из-за чего отчёты отличались друг от друга.
- Добавлена структура клиентского отчёта `report-structure.md`.
- Добавлен дословный текст дисклеймера `legal-disclaimer.md`.
- Добавлен формат внутреннего файла находок `findings-template.md`.
- README переписан под полный порядок работы.

## 07.09.2026 — версия 1

- Методика аудита 152-ФЗ с обязательным порядком работы и таблицей проверки. Находка без
  подтверждённого источника не пишется, непроверенное не попадает в смету.
- Список источников, которые обязательно открыть: тексты документов целиком, HTML-разметка форм,
  JS шаблона, разметка head со счётчиками, реестр Роскомнадзора по ИНН.
- Правила достоверности по разбору реальных ошибок и критерии статусов.
- Самопроверка перед выдачей.
- Скидка 30% при оплате в течение 3 рабочих дней с готовой разметкой блока.
- Правила писем клиенту.
