# Аудиты ADDU

Всё, что нужно для аудитов сайтов ADDU, в одном месте: методики, шаблоны отчётов, правила выдачи
и письма клиенту. Главные правила — в `AGENTS.md`, ассистент читает его сам.

## Структура

```
AGENTS.md          главные правила: режимы работы, выбор методики, что отдаём клиенту
rules-addu.md      скидка 30%, формат выдачи, публикация на case.addu.ru
letters.md         письма клиенту

assets/            общее оформление
  report-template.html   вёрстка отчёта под A4 и PDF
  base-template.html     болванка для маркетинговых отчётов
  design-system.md       принципы оформления
  tariffs.md             тарифы, брать цифры только отсюда
  logo.webp

methods/              методики по типам аудита
  152fz/              аудит по 152-ФЗ + структура отчёта, дисклеймер, QA-эталон
  152fz-intake/       анкета клиенту после оплаты
  152fz-generate/     документы и ТЗ разработчику
  152fz-rkn/          инструкция по уведомлению Роскомнадзора
  market-express.md   маркетинговый разбор по холодному контакту
  market-research/    полное исследование для оплатившего клиента (ConvertMonster)
  tech-site/          технический аудит любого сайта
  tech/               технический аудит на 1С-Битрикс
  cro/                конверсия многостраничных сайтов
  estore/             конверсия интернет-магазинов
  landing/            конверсия лендингов
  seo/                SEO-аудит
  ai-seo/             видимость в нейросетях
  seo-extra/          узкие SEO-задачи
```

## Как подключить

```bash
git clone https://github.com/Valeriakproject/addu-audit.git
```

Дальше **запускать ассистента из папки `addu-audit`** — оттуда он сам читает `AGENTS.md`.

## Как обновляться

```bash
git pull
```

Делать перед началом работы.

## Доступы

Паролей в репозитории нет и быть не должно. FTP для публикации выдаётся лично и хранится только
на компьютере в файле, который не попадает в git.
