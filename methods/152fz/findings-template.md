# Внутренний файл находок

Кроме клиентского отчёта аудит сохраняет внутренний файл `audit-findings.md`. Клиенту он не
показывается. Нужен, чтобы потом можно было собрать анкету и пакет документов, не переделывая
проверку заново.

Формат держать стабильным.

```markdown
# Аудит {URL} по требованиям 152-ФЗ — структурированные находки

Дата аудита: {ГГГГ-ММ-ДД}
Сайт: {URL}
Платформа: {CMS} (по каким признакам определили)
Тип бизнеса: {одна строка}
Контакты на сайте: {телефон, email, адрес}
Оператор: {название, ИНН, ОГРН, адрес}
В реестре РКН: {найден / не найден}

## Сводка

| Серьёзность | Кол-во |
|---|---:|
| критично | N |
| важно поправить | N |
| требует ручной проверки | N |
| ок | N |

  Статус: … Краткое описание проблемы.

отдельной строкой сумма со скидкой и дата, до которой она действует.
```
