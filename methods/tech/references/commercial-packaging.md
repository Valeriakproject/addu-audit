# Коммерческая упаковка техаудита (продажа поддержки)

Цель — превратить технические находки в понятный клиенту повод вести сайт по регламенту
(абонентское обслуживание), а не чинить после поломки.

## Перевод техпроблемы в бизнес-эффект
- обновления → меньше риск взлома и внезапной поломки;
- бэкапы → можно восстановиться после ошибки;
- формы → заявки не теряются;
- скорость → меньше отказов;
- robots/sitemap → каталог лучше индексируется;
- дубли → поисковый трафик не размазывается;
- security headers / HTTPS → защита данных и доверие;
- поддержка → сайт развивается без накопления техдолга.

## Приоритизация
**Срочно (1-2 недели):** редиректы HTTP→HTTPS / www / `/index.php`; корректные robots.txt и sitemap.xml;
title/description/canonical на ключевых шаблонах; базовые security headers; проверка отправки форм и писем;
снять внутренние отчёты (обновления, Проверка системы, Панель безопасности, Панель производительности).

**Планово (1 месяц):** обновить ядро и модули на тестовой копии; обновить Marketplace-решения;
регресс корзины/форм/каталога/поиска/карточек; настроить композит/кэширование; навести порядок в мета-тегах
каталога; настроить мониторинг доступности и ошибок.

**Регулярно (каждый месяц):** проверка обновлений; проверка бэкапов; журнал ошибок и вторжений;
контроль индексации (robots, sitemap, дубли, 404); проверка форм и почты; контроль скорости ключевых страниц;
мелкие правки каталога/шаблонов/интеграций.

## Скрипт разговора на созвоне

НЕ говорить: «у вас всё плохо», «сайт небезопасен», «надо срочно всё переделать».

Говорить:
- «Мы увидели несколько технических зон, которые обычно не закрываются разовой правкой».
- «Часть проблем видна снаружи, часть нужно подтвердить внутри Битрикса».
- «Самое важное: сайт принимает заявки и работает с персональными данными, поэтому его нужно сопровождать по регламенту».
- «Предлагаем не большой проект на неопределённый бюджет, а ежемесячный технический контур: обновления, безопасность, скорость, формы, индексация».

Подача squirrelscan: «Прогнали сайт автоматическим сканером. Даже по быстрой проверке одной главной видно N ошибок
и M предупреждений. Это не значит, что сайт плохой — это накопленный техдолг, который дешевле закрывать по регламенту».

## Привязка к тарифам
Тарифы поддержки — из `../../assets/tariffs.md` (Технический / Стандарт / Премиум / VIP). Сопоставь объём
работ (срочно + планово + регулярно) с часами тарифа и предложи подходящий. «Срочно+планово» обычно укладывается
в первый месяц на Стандарт/Премиум, «регулярно» — это и есть смысл абонентки.
