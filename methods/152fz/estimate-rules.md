# Estimate Rules

Rate: `2500 ₽/час`.

Use the table below for technical implementation estimates. Round totals to 15-minute increments internally, but the client-facing commercial offer should use one fixed price, not a range.

## Standard Work Items

| Work item | Estimate |
|---|---:|
| Create missing privacy / personal data policy page and add footer link | 1 hour |
| Update existing privacy / personal data policy text | 15 min |
| Create separate `Согласие на обработку персональных данных` page | 30 min |
| Update existing consent text | 15 min |
| Add policy + consent links to footer | 15 min |
| Fix broken policy / consent / cookie link | 15 min |
| Add required checkbox and correct policy/consent links in cart/checkout | 30 min |
| Add required checkbox and correct policy/consent links to one other form | 15 min per form |
| Fix one modal form consent block | 15 min per modal |
| Add separate advertising/newsletter consent checkbox | 15 min per form |
| Add cookie notice with links | 15 min |
| Add/update cookie section in policy | 15 min |
| Add external services/processors disclosure to documents | 15 min |
| Check and fix mobile visibility of legal links/forms | 15-30 min |
| Check HTTPS/form submission and fix simple mixed-content/form-link issue | 15-30 min |
| Re-test all fixed forms after implementation | 15-30 min |
| Prepare final client report / implementation note after fixes | 30 min |

## Internal Ranges

Use ranges only internally when thinking through uncertainty:

- the site has multiple Bitrix templates;
- forms are generated by components or external widgets;
- checkout has several steps;
- there are regional mirrors or mobile-specific templates;
- the implementation requires admin/CMS access not available during audit.

Typical internal ranges:

- one simple site with 1-3 forms: `2-4 hours` / `5 000-10 000 ₽`;
- site with several forms and checkout: `4-7 hours` / `10 000-17 500 ₽`;
- complex e-commerce / booking / medical / education site: `7-12 hours` / `17 500-30 000 ₽`;
- many templates, widgets, or unclear CMS state: `12+ hours`; for a client PDF, either quote a fixed first-stage package for the clearly listed scope or separate uncertain items into manual review.

## Calculation Rules

- Convert minutes to hours: 15 min = 0.25 h, 30 min = 0.5 h.
- Multiply by `2500 ₽/час`.
- Show exact hours and exact rubles in the client-facing offer.
- If internal uncertainty remains, choose a reasonable fixed quote by rounding up to the nearest 0.5 hour.
- Do not write `после доступа к CMS уточним оценку` in the client-facing offer. The offer is for the listed technical scope.
- If the same form template is reused across many pages, estimate the template once and add retest time.
- If forms are technically different, estimate each form separately.

## Fixed Price Examples

- internal estimate `5.5-6.5 hours` -> client offer `6 hours / 15 000 ₽`;
- internal estimate `3.25 hours` -> client offer `3.5 hours / 8 750 ₽`;
- internal estimate `7.75 hours` -> client offer `8 hours / 20 000 ₽`.

## What Not to Price as Technical Work

Separate these from the technical estimate:

- legal review of wording;
- Roskomnadzor notification;
- internal data-processing regulations;
- contracts with processors;
- database localization audit;
- CRM storage/deletion process audit.

Mention them as `требует ручной юридической / организационной проверки`.
