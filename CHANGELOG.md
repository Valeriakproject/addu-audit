# Изменения

## 09.09.2026 — версия 8

- Добавлена папка `examples/` с готовыми аудитами-эталонами: 152-ФЗ со скидкой и два конверсионных.
  В правила добавлен пункт сверяться с примером перед сдачей.
- В README примеров указана ссылка на открытый репозиторий с полными комплектами по всем типам аудита.

## 09.09.2026 — версия 7

- Перенесён весь конвейер 152-ФЗ после оплаты: анкета клиенту, генерация документов и ТЗ
  разработчику, инструкция по Роскомнадзору. Раньше их не было, продать могли, а сдать нечем.
- Добавлен универсальный технический аудит `tech-site` (сканер плюс проверка в браузере), не
  привязанный к Битриксу.
- Добавлен QA-эталон `methods/152fz/qa-review-rules.md` с разбором реальных ошибок, полный чек-лист
  требований и подробные нормы времени.
- В методику 152-ФЗ дописано: предупреждение про сайты на JavaScript (статический запрос отдаёт
  пустую оболочку, проверять в браузере), калибровка статусов по реальным примерам, проверка на
  самопротиворечие статуса и раздела «что уже в порядке».
- Добавлены узкие SEO-методики в `methods/seo-extra/`.

## 09.09.2026 — версия 6

- Перенесены все методики: технический аудит, CRO, интернет-магазины, лендинги, SEO, ИИ-аудит,
  полное маркетинговое исследование ConvertMonster. Теперь всё в одном репозитории, второй источник
  не нужен.
- Появилась структура: `methods/` по типам аудита, `assets/` с общим оформлением и тарифами.
- Абсолютные пути заменены на относительные — раньше в файлах были пути с чужого компьютера.
- `AGENTS.md` переписан: режимы работы, таблица выбора методики, общие правила и что отдаём клиенту.

## 09.09.2026 — версия 5

- Добавлен `market-express.md` — экспресс-разбор маркетинга для холодного контакта. Работает только
  по открытым источникам: сайт и путь покупателя, цены, конкуренты из выдачи, отзывы, видимые каналы,
  рыночные данные веб-поиском. Ничего у клиента не спрашивает.
- Причина: скилл полного маркетингового исследования требует бриф из 11 полей и на холодном лиде
  вставал, потому что спросить выручку и средний чек не у кого.
- В `AGENTS.md` добавлена таблица выбора методики под запрос.

## 09.09.2026 — версия 4

- Правило про запрет вопросов сужено до пресейла. Раньше оно распространялось на весь репозиторий
  и сломало бы полное маркетинговое исследование по ConvertMonster, где вводные у клиента собирать
  нужно. Теперь явно описаны два режима: пресейл по холодному контакту и работа с оплатившим клиентом.

## 09.09.2026 — версия 3

- Добавлено главное правило: аудиты пресейловые, делаются без контакта с клиентом. Ассистенту
  запрещено спрашивать выручку, средний чек, аудиторию, конкурентов и приоритетные запросы.
  Недостающее помечается как «требует уточнения у клиента», работа не отменяется.
  Причина: на маркетинговом и ИИ-аудите ассистент вставал и требовал вводные, которых взять негде.

- Добавлен дословный текст дисклеймера `legal-disclaimer.md`.
- Добавлен формат внутреннего файла находок `findings-template.md`.
- README переписан под полный порядок работы.
