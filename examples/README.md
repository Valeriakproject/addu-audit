# Примеры готовых аудитов

Эталоны «как должно получиться». Сверяй свой результат с ними: структура, глубина находок, тон,
вёрстка, оформление сметы. Не копируй текст, копируй уровень.

| Файл | Что показывает |
|---|---|
| `research-korcosshop-ru.html` | **Маркетинговое исследование по холодному контакту.** Главный эталон для исследований: рынок со ссылками и статусами данных, таблица конкурентов с реальными ценами, аватары, матрица сегментов, план на 90 дней, риски и раздел «что уточняем на созвоне». Опубликовано: https://case.addu.ru/korcosshop.ru/research/ |
| `152fz-by-addu-ru.html` | Аудит по 152-ФЗ: карточки статуса, находки, смета и блок со скидкой 30% |
| `cro-van-kovka-ru.html` | Конверсионный аудит многостраничного сайта со скриншотами |
| `cro-vcolorite-ru.html` | Конверсионный аудит, компактный вариант |

Больше готовых примеров по всем типам аудита (технический, SEO, AI SEO, 152-ФЗ, CRO) —
в открытом репозитории <https://github.com/StanislavKlodt/addu-audit-examples>. Хороший полный
комплект там — папка `babyplusmed.ru/`.

Примеры — это клиентские работы. Внутренние материалы, письма менеджеру и машинные находки в них
не входят.
